# План создания платформы киберфутбольных турниров

Документ написан так, чтобы его можно было целиком скормить нейросети/AI-агенту (Claude Code, Cursor, Devin и т.п.) и она поэтапно реализовала проект. Это не копия cyberfootball.online, а самостоятельный продукт с похожей нишей (турниры по FIFA/eFootball/EA FC), но с другим дизайном, названием и набором фич.

---

## 1. Название и позиционирование

Варианты названия (проверь свободность домена и товарного знака перед использованием):

- **ProGoal Arena** — про-турниры, ассоциация с ареной киберспорта
- **KickLeague.gg** — короткое, доменно-дружелюбное, в стиле esports-брендов
- **Neon11** — 11 игроков на поле, неоновая эстетика
- **PitchZone** — "зона поля", современно и нейтрально
- **FUTclash / Clash Pitch** — акцент на соревновательность

Рекомендация: **PitchZone** — легко произносится на разных языках, домен pitchzone.gg / pitchzone.online, хорошо ложится на неоновый/тёмный дизайн.

Позиционирование: "Турнирная платформа нового поколения для киберфутбола — честные турниры, мгновенные выплаты, прозрачный рейтинг".

---

## 2. Чем сайт будет отличаться от cyberfootball.online (улучшения)

1. **Современный UI на тёмной теме с неоновыми акцентами** вместо стандартного "спортивного портала" — карточки турниров с живой анимацией, motion-эффекты при наведении, стеклянные (glassmorphism) панели.
2. **Прозрачная система эскроу для призовых** — деньги участников блокируются на платформе до окончания турнира и автоматически распределяются по итогам (комиссия площадки списывается автоматически, не вручную).
3. **Рейтинговая система (Elo/MMR)** для игроков и команд с публичным профилем, историей матчей, статистикой (аналог рейтинга в киберспорте, а не просто "победы/поражения").
4. **Античит и верификация результатов**: обязательная загрузка скриншота/видео результата матча + возможность оспорить результат (dispute-система с модератором), защита от накрутки.
5. **Гибкая комиссия организатора**: платформа берёт % не только с призового фонда турниров, но даёт возможность командам создавать закрытые платные турниры между собой (комиссия за организацию).
6. **Мультивалютные платежи и локальные способы оплаты** (карты, СБП/аналоги, крипто-кошелёк как опция) — шире, чем обычно у конкурентов.
7. **Live-сетка турнира (bracket) в реальном времени** с обновлением через WebSocket — зрители видят live-статус матчей без перезагрузки страницы.
8. **Мобильное PWA-приложение** — конкурент, скорее всего, чисто веб; PWA даёт пуш-уведомления о начале матча.
9. **Реферальная и партнёрская программа** для организаторов сообществ (создателям турниров — процент с комиссии площадки).
10. **Прозрачный публичный API** для сообществ и стриминговых оверлеев (данные турнира можно вывести в OBS).

## 3. Дизайн-концепция

Стиль: **тёмный киберспортивный минимализм** — не "перегруженный esports с драконами", а сдержанный, как у современных SaaS-продуктов (Linear, Vercel) но с спортивной энергией.

- **Тема**: тёмный фон (почти чёрный, #0B0D12), один яркий акцентный цвет — электрик-лайм (#C6FF3D) или неон-циан (#3DE7FF), плюс градиенты для карточек призовых фондов.
- **Типографика**: жирный гротеск для заголовков (например, Space Grotesk / Clash Display), нейтральный sans (Inter) для текста.
- **Компоненты**:
  - Карточка турнира: превью-баннер, живой счётчик "до старта", призовой фонд крупным шрифтом, статус (open/live/finished) цветным индикатором.
  - Bracket-визуализация: анимированные линии соединения, подсветка активного матча.
  - Профиль игрока: радар-диаграмма статистики, график изменения рейтинга во времени.
  - Микро-анимации на hover/scroll (Framer Motion), но без перегруза — производительность важнее эффектов.
- **Адаптивность**: mobile-first, т.к. большая часть аудитории заходит с телефона перед матчем.

## 4. Технический стек

**Frontend**

- Next.js 14+ (App Router) + TypeScript
- Tailwind CSS + shadcn/ui (компоненты)
- Framer Motion (анимации)
- Zustand или React Query для стейта/данных
- Socket.io-client / WebSocket для live-обновлений сетки

**Backend**

- Node.js (NestJS) или Go (если нужна высокая нагрузка/live-данные) — для старта NestJS проще
- PostgreSQL (основная БД: пользователи, турниры, матчи, транзакции)
- Redis (кэш, очереди, live-статусы матчей, rate limiting)
- WebSocket-сервер (Socket.io / native ws) для live-сетки и чата

**Платежи и деньги**

- Провайдер эскроу-платежей: Stripe Connect (для международных выплат) + локальный провайдер (ЮKassa/CloudPayments для СНГ, если нужно)
- Отдельный микросервис "Wallet" — баланс пользователя, история транзакций, автоматическое распределение призовых по итогам турнира

**Инфраструктура**

- Docker + docker-compose для dev, Kubernetes (или просто Render/Railway/Fly.io) для прод на старте
- Object storage (S3-совместимый, напр. Cloudflare R2) — для скриншотов/видео результатов матчей
- CI/CD: GitHub Actions
- Мониторинг: Sentry (ошибки), Grafana + Prometheus (метрики)

**Прочее**

- Auth: NextAuth/Auth.js или Clerk (email, Steam/Discord OAuth — актуально для геймеров)
- Уведомления: email (Resend/SendGrid) + push (веб-пуш/PWA) + опционально Telegram-бот
- Античит/верификация: ручная модерация + загрузка пруфов, в будущем — интеграция с API игры (если EA FC/eFootball это позволяют) для авто-подтверждения счёта

## 5. Ключевые модули платформы

1. **Auth & профили** — регистрация, OAuth, профиль игрока/команды, статистика, рейтинг.
2. **Турниры** — создание (админ или верифицированные организаторы), форматы: single/double elimination, round robin, swiss.
3. **Регистрация и оплата взноса** — участник/команда платит взнос, деньги уходят в эскроу-кошелёк турнира.
4. **Матчи и сетка** — live bracket, ввод и подтверждение счёта, система оспаривания.
5. **Кошелёк и выплаты** — баланс, вывод средств, история операций, автоматическое начисление призовых.
6. **Комиссии платформы** — конфигурируемый % с призового фонда и/или с взноса за участие; отдельная комиссия для команд, создающих собственные закрытые турниры.
7. **Модерация и античит** — жалобы, бан-система, проверка пруфов результатов.
8. **Уведомления** — email/push/Telegram о начале матча, окончании регистрации, начислении выигрыша.
9. **Админ-панель** — управление турнирами, пользователями, финансами, отчётность по комиссии.
10. **Публичный API / виджеты** — для встраивания турнирной сетки на сторонние сайты и в стрим-оверлеи.

---

## 6. Монетизация (как зарабатывать)

- Комиссия с призового фонда каждого турнира (например, 5–15%, настраивается по типу турнира).
- Комиссия за создание платных приватных турниров между командами.
- Платная верификация/выделение турнира (буст в списке, баннер).
- Подписка для организаторов сообществ (расширенная аналитика, кастомный брендинг турниров, отсутствие комиссии платформы взамен на фикс. плату).
- Реклама/спонсорские слоты на страницах турниров.

## 7. Поэтапный план для AI-агента (промпты можно копировать по очереди)

### Этап 0 — Подготовка

- Создать репозиторий, настроить монорепо (turborepo или nx): `apps/web`, `apps/api`, `packages/ui`, `packages/config`.
- Настроить Docker Compose с Postgres + Redis для локальной разработки.
- Настроить линтеры, prettier, husky pre-commit.

### Этап 1 — Дизайн-система

- Создать Tailwind-конфиг с палитрой (см. раздел 3), подключить шрифты Space Grotesk + Inter.
- Собрать базовые UI-компоненты (Button, Card, Badge, Modal, Table) на основе shadcn/ui с кастомной темой.
- Сверстать статичные мокапы главной страницы, страницы турнира, профиля игрока.

### Этап 2 — Auth и профили

- Реализовать регистрацию/логин (email + OAuth Discord/Steam).
- Модель пользователя: ник, аватар, страна, статистика, рейтинг Elo.
- Страница профиля игрока и команды.

### Этап 3 — Турниры и сетка

- CRUD турниров (создание, редактирование, форматы: single/double elimination, round robin).
- Регистрация участников/команд на турнир.
- Генерация и визуализация сетки (bracket), включая live-обновления через WebSocket.

### Этап 4 — Матчи и результаты

- Экран матча: ввод счёта, загрузка скриншота/видео как пруфа.
- Система подтверждения результата обеими сторонами.
- Модуль оспаривания (dispute) с очередью модерации.

### Этап 5 — Кошелёк и платежи

- Интеграция Stripe Connect (+ локальный провайдер, если нужно).
- Механизм эскроу: заморозка взносов участников, авторасчёт призовых по завершении турнира с автоматическим удержанием комиссии платформы.
- История транзакций и вывод средств.

### Этап 6 — Уведомления и коммуникации

- Email-уведомления (регистрация, начало турнира, начало матча, результат).
- Веб-пуш через PWA.
- (опционально) Telegram-бот для уведомлений сообществам.

### Этап 7 — Админ-панель

- Управление турнирами, пользователями, спорами, финансовой отчётностью.
- Настройка комиссии платформы по типам турниров.

### Этап 8 — Полировка и запуск

- Оптимизация производительности (Lighthouse), SEO-мета, OpenGraph превью турниров.
- Тестирование платежного флоу в песочнице.
- Настройка мониторинга (Sentry, Grafana) и деплой в прод.

---

## 8. Юридический момент (важно)

Приём денег с игроков за участие в платных турнирах с призовым фондом в ряде юрисдикций регулируется законами об азартных играх/лотереях в зависимости от формата (skill-based турниры обычно регулируются мягче, чем game-of-chance, но правила отличаются по странам). Перед запуском стоит проконсультироваться с юристом по теме приёма платежей, эскроу и организации платных киберспортивных турниров в тех странах, где планируется работать — это не то, что можно определить только техническим планом.
